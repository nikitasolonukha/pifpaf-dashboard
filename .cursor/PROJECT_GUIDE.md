# Website Pack

For custom sites, landing pages, promo sites, frontend-heavy builds, Tailwind/React/Vite/Next style repos.

## Recommended global MCPs
- github
- figma
- tavily
- context7
- vercel (when relevant)
- snyk only when it actually works in your environment

## Recommended local MCPs
- playwright

## Why local-only MCP here
Local MCP keeps the project isolated and avoids loading extra tools into every repo.
